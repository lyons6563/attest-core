# Extension Icons

The extension references icon files (`icon16.png`, `icon48.png`, `icon128.png`) in `manifest.json`.

**For initial testing, these are optional** - Edge/Chrome will use a default icon if missing.

To add custom icons later:
1. Create PNG images at 16x16, 48x48, and 128x128 pixels
2. Place them in the `browser_extension` folder
3. The extension will automatically use them
